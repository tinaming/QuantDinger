2. Contract

  • Prefer four-way columns + edge trigger (false→true only).
  • Declare # signal_form, # exit_owner, # flip_mode in the header.
  • output['signals'] is display-only; fills use execution columns.
def edge(s):
    s = s.fillna(False).astype(bool)
    return s & ~s.shift(1).fillna(False).astype(bool)

3. Minimal example

# signal_form: four_way
# exit_owner: engine
# flip_mode: R1
# @strategy stopLossPct 0.03
# @strategy takeProfitPct 0.06
# @strategy tradeDirection both

my_indicator_name = "CZSC bi flip"
df = df.copy()
bi = df["czsc_bi_dir"].fillna(0)
bi_prev = bi.shift(1).fillna(0)
flip_up = (bi == 1) & (bi_prev != 1)
flip_dn = (bi == -1) & (bi_prev != -1)

def edge(s):
    s = s.fillna(False).astype(bool)
    return s & ~s.shift(1).fillna(False).astype(bool)

df["open_long"] = edge(flip_up)
df["close_long"] = edge(flip_dn)
df["open_short"] = edge(flip_dn)
df["close_short"] = edge(flip_up)
output = {"name": my_indicator_name, "plots": [], "signals": []}

4. Backtest (secondary)

Enable strict mode before go-live: confirmed closed-bar signals, default next-bar open fills. Align exit_owner / flip_mode with live trading_config.
