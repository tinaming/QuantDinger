1. 缠论核心：结构 → 信号

本平台在跑指标 / 回测 / 实盘前，会把缠论结构写成 df 上的列：

结构你在策略里读什么典型用法
分型czsc_fx_mark / czsc_fx_price顶底确认、突破过滤
笔czsc_bi_dir 及起止价、长度方向翻转开仓
线段czsc_duan_dir 及起止价大级别方向过滤
中枢czsc_zs_zd / zg / position震荡区间、离开中枢
买卖点czsc_bs_type（如 1buy…3sell）结构买点过滤
趋势 / 背驰czsc_trend / czsc_beichi / czsc_bi_force顺势、背驰确认
多级别代理czsc_ml_align笔/段同向共振
硬性约束：指标沙箱不能 import czsc（含原生扩展）。只读已注入的 czsc_* 列，再写出 open_long 等执行列。

2. 常用列速查

列含义
czsc_fx_mark1 顶分型，-1 底分型
czsc_bi_dir笔方向：1 上，-1 下
czsc_duan_dir线段方向
czsc_zs_positionabove / below / inside
czsc_bs_type买卖点字符串；无则为空
czsc_trend1 上涨，-1 下跌，0 盘整
czsc_ml_align1 笔段同向，-1 反向

若列全为 0 / 空，先确认服务端缠论库可用；校验阶段可能注入 mock 列以防 KeyError。

3. 信号契约（必须对齐）

语义以平台信号与执行标准为准，不要自创列含义：

  • 推荐形态 B 四路：open_long / close_long / open_short / close_short
  • 边缘触发：只在 false→true 记一次信号（用 edge()）
  • 头注释声明：# signal_form: four_way、# exit_owner: engine|indicator、# flip_mode: R1|R2
  • output['signals'] 只画图，成交只认执行列
  • exit_owner: engine → 可用引擎止盈止损；indicator → 用 close_* 自己平，并关掉 trailing
def edge(s):
    s = s.fillna(False).astype(bool)
    return s & ~s.shift(1).fillna(False).astype(bool)
缠论「结构条件」先算成布尔序列，再 edge(...) 写入四路列——结构可持续成立，信号只在翻转瞬间触发。

4. 最小可跑示例：笔翻转 + 买卖点

# signal_form: four_way
# exit_owner: engine
# flip_mode: R1
# @strategy stopLossPct 0.03
# @strategy takeProfitPct 0.06
# @strategy tradeDirection both

my_indicator_name = "缠论笔翻转"
my_indicator_description = "笔方向翻转，并用买卖点/趋势过滤"

df = df.copy()

bi = df["czsc_bi_dir"].fillna(0)
bi_prev = bi.shift(1).fillna(0)
bs = df["czsc_bs_type"].fillna("").astype(str)
trend = df["czsc_trend"].fillna(0)

flip_up = (bi == 1) & (bi_prev != 1)
flip_dn = (bi == -1) & (bi_prev != -1)
has_buy = bs.str.contains("buy", case=False, na=False) & (bs != "")
has_sell = bs.str.contains("sell", case=False, na=False) & (bs != "")

long_cond = flip_up & (has_buy | (trend >= 0)) & (trend >= 0)
short_cond = flip_dn & (has_sell | (trend <= 0)) & (trend <= 0)

def edge(s):
    s = s.fillna(False).astype(bool)
    return s & ~s.shift(1).fillna(False).astype(bool)

df["open_long"] = edge(long_cond)
df["close_long"] = edge(short_cond)
df["open_short"] = edge(short_cond)
df["close_short"] = edge(long_cond)

output = {
    "name": my_indicator_name,
    "plots": [],
    "signals": [
        {"type": "buy", "text": "OL", "color": "#00E676",
         "data": [1 if x else None for x in df["open_long"]]},
        {"type": "sell", "text": "OS", "color": "#FF5252",
         "data": [1 if x else None for x in df["open_short"]]},
    ],
}

结构如何映射到进出场

缠论事件建议执行列
向上笔确立 / 买点出现open_long（可同时 close_short）
向下笔确立 / 卖点出现open_short（可同时 close_long）
仅平仓不反手只写对应 close_*，不要写对侧 open_*
中枢内震荡收紧开仓；或用 position == "inside" 过滤

5. 多级别与内置模板

  • 同向过滤：要求 czsc_ml_align == 1，或 czsc_duan_dir 与 czsc_bi_dir 一致。
  • IDE 可选用缠论草稿模板，例如：分型突破、中枢震荡、买卖点趋势、多级别共振、真三买回踩。
  • 模板已按四路 + 边缘触发写好；改完务必再跑严格模式回测。
Agent / 研究工具可分析缠论结构；落成可回测策略仍须写出完整 Python 指标代码（不能把自然语言塞进 code）。

6. 回测（辅）：严格模式怎么跑

回测用来验证缠论信号是否过密、成交时点是否合理，不是教程主体。

模式行为用途
严格已收盘确认信号 → 默认下一根开盘成交上线前必开，与默认实盘对齐
非严格更激进（可当根收盘等）盘感试探，不宜单独当上线依据
  1. 写好四路信号与契约头注释
  2. 选市场 / 标的 / 周期
  3. 打开严格模式 → 运行回测
  4. 看资金曲线、回撤、成交明细；信号过密先查是否漏了 edge()
  5. 满意后保存指标 → 保存为策略 → 再跑一次策略回测
缠论策略额外核对：czsc_* 非空、买卖点字符串符合预期、多级别过滤没有把有效信号滤光。

7. 上线前检查

  • 未使用 import czsc / shift(-1)
  • df = df.copy()；执行列为 bool 且已边缘触发
  • exit_owner 与引擎 trailing / 止盈止损不冲突
  • 严格模式回测通过；实盘 trading_config.strict_mode: true
  • flip_mode 回测与实盘一致
