- 所有 MCP 工具函数均使用 `@mcp.tool()` 装饰器注册，并通过统一的 `_get/_post/_patch` + `_unwrap` 访问 REST，错误路径返回 `{error: True, status, body/text}` 结构。
- 进入后端的可变参数先经 `assert_json_dict(name, value)` 强类型校验，再拼入 payload，避免把 None 或列表误传为 JSON object。
- 所有可能包含凭据的响应体在返回前经过 `redact_secrets` 递归扫描 `_SECRET_KEYS` 白名单，将真实值替换为 `***`。
- 长耗时任务（job SSE / 轮询）一律设置硬上限：`max_events`、`max_seconds`、`timeout_s`，并在 `consume_job_stream` / `poll_job_until_terminal` 中显式截断，防止 MCP 客户端挂起。
- 环境变量读取统一走 `_env(name, required=True)` 辅助函数，缺失时打印 `[ChanQuant-mcp] missing required env var:` 并以 exit code 2 退出。
- 工具文档字符串采用 Args: 段落风格描述参数约束（如 limit 范围、timeframe 枚举），与 `MCP_TOOL_NAMES` 常量保持同步以便测试漂移检查。
