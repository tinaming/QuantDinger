模块以 `src/ChanQuant_mcp/server.py` 为唯一入口，通过 `pyproject.toml` 的 `[project.scripts] ChanQuant-mcp = "ChanQuant_mcp.server:main"` 注册 CLI；`security.py` 提供客户端侧安全护栏（代码大小断言、JSON 类型校验、敏感字段脱敏、SSE 解析与带上限的流消费），被 server 层复用。

- 进程模型：单进程 httpx Client + FastMCP 实例，按 `ChanQuant_MCP_TRANSPORT` 在 stdio / SSE / streamable-http 三种传输间切换，HTTP 模式下由 `ChanQuant_MCP_HOST`/`PORT` 控制监听地址。
- 对外边界：所有 MCP 工具都是对 `/api/agent/v1/*` REST 的薄封装，不持有业务状态；认证通过 `ChanQuant_AGENT_TOKEN` 注入 Bearer header，租户隔离完全委托 Gateway 后端。
- 职责分层：
  - `server.py`：定义 `FastMCP("ChanQuant")` 实例，用 `@mcp.tool()` 装饰器注册 Read/R、Workspace W、Backtest/B 三类工具（交易 T 故意不暴露）；统一 `_get/_post/_patch` + `_unwrap` 处理响应并调用 `redact_secrets`。
  - `security.py`：纯函数库，实现 `assert_indicator_code_size`、`assert_json_dict`、`redact_secrets`、`parse_sse_chunk`、`consume_job_stream`（带 max_events/max_seconds 硬上限）、`poll_job_until_terminal`（轮询至 succeeded/failed/cancelled）。
- 依赖方向：server → security → httpx/mcp；无反向依赖，也不直接 import 上层量化引擎，仅作为网关的 MCP 适配层。
- 部署形态：`Dockerfile` 使用 `python:3.12-slim-bookworm`，默认以 `streamable-http` 模式在 7800 端口启动；`railway.json` 用于 Railway 平台一键部署。
