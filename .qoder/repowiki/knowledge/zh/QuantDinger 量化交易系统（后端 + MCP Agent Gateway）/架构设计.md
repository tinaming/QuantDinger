根目录作为多子模块编排层，包含两个独立可部署的 Python 服务：
- `backend_api_python`：Flask + flask-smorest 主应用，承载用户/策略/回测/网格/实盘/支付等全部业务，并通过 `app/openapi/blueprint.py` 统一注册路由、生成 `docs/api/openapi.yaml`。
- `mcp_server`：FastMCP 网关，复用同一份 Agent REST API（由 backend 提供），仅做协议转换，不重复实现业务逻辑。

跨子模块的耦合点：
- 共享契约：`docs/api/openapi.yaml` 与 `docs/agent/agent-openapi.json` 是后端与 MCP 服务器的共同接口基线，CI 在 `.github/workflows/openapi-ci.yml` 中校验一致性。
- 版本同步：顶层 `VERSION` 与 `backend_api_python/VERSION`、`mcp_server/pyproject.toml` 由 `scripts/bump_version.py` 统一打标签，保证发布镜像 tag 一致。
- 容器编排：`docker-compose.yml` / `.ghcr.yml` 将两个服务以相同网络启动，MCP Server 通过环境变量指向后端地址。
- 开发工具链：`.spectral.yaml` 对 OpenAPI 进行规范检查，`scripts/export_openapi.py` 从后端导出 schema 供 MCP 侧消费。

因此，新增功能应在后端先落地并更新 OpenAPI，再由 MCP 侧自动获得新工具，避免双写。
