- 所有人类-facing 路由通过 `app.openapi.blueprint.HumanBlueprint` 注册，由装饰器自动附加 200/400 标准信封响应 schema，SSE 端点通过规则后缀白名单跳过信封。
- 可插拔的外部依赖（ib_insync、MetaTrader5、alpaca-py）一律在函数体内 lazy import，未安装时抛出带安装提示的 `LiveTradingError`，避免主进程启动失败。
- 工厂类（`data_sources.factory.DataSourceFactory`、`services.live_trading.factory.create_client`）通过 `exchange_id`/`market` 字符串匹配分发到具体实现，并使用 `_MARKET_ALIASES` 或 root overlay keys 兼容前端多种命名变体。
- 后台常驻任务（挂单 worker、网格轮询、USDT 监听、AI 校准/反思）均通过 `app/startup.run_startup_hooks` 在 app 上下文内按需启动，并以 `ENABLE_*` 环境变量开关，且跳过 Flask reloader 父进程。
- 配置项统一通过 `app.config.settings.Config` 元类属性暴露，优先读 `PYTHON_API_*` 环境变量，再 fallback 到默认值，运行时参数走 `load_addon_config` 合并。
- 日志通过 `app.utils.logger.get_logger(__name__)` 获取结构化 logger，关键路径异常统一 `logger.error(..., exc_info=True)` 记录堆栈。
